<p>做长期批量投放的人，问价方式往往和散户不一样：开口就是「一个月大概多少」，而不是「一条多少钱」。这背后的逻辑是，住宅 IP 的账单跟用量强相关，按量计费的好处是花多少算多少，坏处是算不清就会超支。这篇按三类真实场景拆开讲，先给出报价的构成项与经验区间，再分别给出用量的估算方法，最后附一张可以直接填数的试算表。文中价格为经验区间，仅供参考。</p>
<h2>一、先按并发形态分档，而不是按号量</h2>
<p>十个号轮着用和十个号同时在线，成本能差五倍以上。所以分档的第一依据是并发形态：是每天固定几个小时集中使用，还是项目来了几天冲高、平时几乎不动，还是常年保持低并发养着。</p>
<h3>分档依据为什么不是号量</h3>
<p>号量只决定你需要多少条出口，并发才决定你同一时刻占用多少资源。按量计费里流量和并发是两笔不同的钱：流量按 GB 走，并发按占用时间走。号多但错峰用，流量不涨；号少但在同一分钟全跑起来，并发费用立刻上去。</p>
<h3>三档之间的边界</h3>
<p>日均在线不足三小时、峰值并发不超三，算低并发；单次持续不超过五天、峰值并发突然翻三倍以上，算项目制冲量；日均在线八小时以上、并发基本恒定，算常态化高占用。边界不必精确，但要先认领一档，报价才有可比性。</p>
<h2>二、报价行情：按量计费的四个构成项</h2>
<p>市面上报价差异很大，一半来自线路品质，一半来自计价单位的口径。问价时把四件事分开问，就不容易被一个「每 GB 多少钱」绕进去。</p>
<h3>单价为什么能差三倍</h3>
<p>同样是住宅段，独享原生家宽的单价通常是共享池的两到三倍，因为一条线路只服务一个人，复用率低。愿意接受共享池，单价能压下来，但要承担同段其他人行为带来的历史记录。长期投放用的号，建议关键账号走独享，测试与采集走共享。</p>

<h2>三、场景一：常态化低并发盯数据</h2>
<p>典型画像是三到五个人，每天上午和晚上各看一轮后台，中间偶尔跑几次接口。特点是总量不大但时间分散，最忌讳为这点用量签一张包月底价单。</p>
<h3>月用量怎么估</h3>
<p>拿一周的真实日志出来，把每次会话的请求数、平均响应体大小、持续时长列出来，乘以四得出月量，再上浮三成留余量。经验值：纯文本接口单号一天几万次请求，流量通常在 2–5 GB 之间；带页面截图或文档解析的场景能到 20 GB 以上，差别极大，只能实测。</p>
<h3>适配结论</h3>
<p>这一档用按量最划算，建议只买断流量不锁并发，遇到临时加班再加一小时并发。注意把粘性调到账号级固定，否则省下来的流量钱会赔在反复验证上。</p>
<h2>四、场景二：项目制短期冲量</h2>
<p>投放前的素材复核、竞品批量抓取、A/B 组数据回收，都属于这一类：三五天内并发从 3 冲到 15，之后迅速回落。按量计费天生适合这种波形。</p>
<h3>峰值并发怎么买</h3>
<p>不要按瞬时最高值买满。做法是把一天的请求按时段画出来，取第 95 百分位作为购买并发，剩下 5% 的时间排进队列慢慢消化。这样通常能省三到四成费用，代价只是几分钟的排队延迟。</p>
<h3>释放与回收要当天做</h3>
<p>冲量结束后立刻释放并发额度，别留在账号里等下次。多数服务商按小时计费，多挂一天就多一天的钱。把释放动作写进项目收尾清单，比事后对账有效。</p>
<h2>五、场景三：批量投放前的成本试算</h2>
<p>正式放量前，先跑一个七天的试算周期，用小批量号把三个数打出来：单号日均流量、日均在线时长、峰值并发。这三个数定了，月成本基本就定了。</p>
<h3>试算表怎么排</h3>
<p>按号段分组填，同一组用同一档线路，方便横向比。填完先看两个比值：每号每天成本、每千次成功请求成本。前者看绝对值，后者看效率，两个一起看才不会被低价线路骗。</p>

<h3>哪几种情况不适合按量</h3>
<p>三种：第一，每天在线超过十小时且并发稳定，包月单价更低；第二，要求出口地址长期不变，按量池很难保证；第三，账号数量固定且需要严格一号一线，独享比按量可控。这三种都别硬套按量，省下的钱不够补环境的窟窿。</p>
<h2>常见问答</h2>
<h3>按量计费的流量是双向都算吗？</h3>
<p>答：各家口径不同，有的只计上行，有的上下行合并。问价时要求对方明确写出计量方向，并在试用期用自己的日志对一次账。差一倍的情况真实存在，签之前对清楚。</p>
<h3>预估月用量总是偏差很大怎么办？</h3>
<p>答：先缩小统计粒度。按小时记录请求数与响应体大小，找出一周里的最高时段，用这个时段乘系数代替平均值，误差会小很多。平均法在波形明显的场景里几乎必错。</p>
<h3>共享池和独享线路可以混着买吗？</h3>
<p>答：可以，而且常见。建议注册与订阅相关的账号走独享，采集、查重、素材比对走共享池。两组之间不要共用浏览器环境和 Cookie，否则独享的意义就没了。</p>
<h3>报价里没写换线费用，算不算已经包含？</h3>
<p>答：不能这么理解。默认按不包含处理，让对方在报价单上补一行：故障换线是否收费、多久生效、是否保留原城市。这三条写清楚，后面才不用反复沟通。</p>
